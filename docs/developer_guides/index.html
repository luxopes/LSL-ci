0.8.5 Rychlejší compiler

Lux Simple Lang

Compiler skládá kód, data i ELF obraz v ByteArray, lexer čte zdroj po UTF-8 bajtech a codegen uklízí po větších dávkách funkcí. Generovaný kód, runtime ani jazyk se nemění: binárky z 0.8.4 a 0.8.5 jsou shodné.
